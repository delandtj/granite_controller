# PM-19V-250W rev C: start here

Restart point for the next port module, written 2026-11-26 for a design
start on 2026-11-27. Self-contained; the wider bench history is
docs/handoff.md, the order that triggered this is docs/fd-batch2-order.md.

## Why a rev C now

- The FD batch 2 order (2026-11-26, two pods) could only get modules for
  one pod: JLC had 115 MCP65R46T-2402E/CHY (C623510, U2 / U3, two per
  module) against 200 needed. The user ordered **50 PM-19V-250W-B** (one
  pod, 100 comparators, inside stock). After that order JLC has ~15 left.
- **The second pod's 48 modules are to be rev C**, not a B reorder with a
  pre-ordered comparator (user, 2026-11-26).
- So the rev C bill of materials must be buildable at JLC for 100+
  modules without global sourcing or pre-orders (user: global sourcing is
  not an option for dates).

## Starting point

- Rev B is the base: LM5116 single-phase buck, 38-66 V in, 19.0 V /
  13.2 A out. Spec: docs/pm-19v-250w-b.md (design calculations with the
  LM5116 SNVS499I equation numbers, BOM, layout rules, open risks,
  decisions). Sources: power/pm-19v-250w-b/ (schematic generated by
  tools/gensch.py, placement tools/place.py, tools/build.sh, pcbkit.toml).
- Rev B is proven on the bench: 4 modules on two units, 48.1 V in, comes
  up ON with the plane's power-up clear and 7c / 7d latch handling.
- Rev A (power/pm-19v-250w/, LTC7810 two-phase) is out: U1 LTC7810
  (C581067) is out of stock and the bench modules showed ~14 W idle
  loss and unwetted coil joints. Do not start from it.
- Suggested name and place: PM-19V-250W-C, power/pm-19v-250w-c/, spec
  docs/pm-19v-250w-c.md (a component spec in the style of the B doc, not
  an implementation plan).

## Fixed: the interface (do not change)

From docs/pm-interface.md and the B doc section 2; batch 2 units are
built for it:

- Outline 58.4 x 22.9 mm, 4 layers, 1.6 mm, ENIG.
- Screws (block centre coordinates): S1 VIN (-25.70, -7.95), S2 GND
  (-25.70, +5.95), S3 GND (+25.70, +5.95), S4 VOUT (+25.70, -7.95);
  footprint pm:PM_Mount_M2.
- J2 aux header on the B side at (+12.70, -7.85), pm:PM_Aux_Header_2x03_P1.27:
  1 OV_KILL (open drain, low = over voltage; the unit pulls it up to
  3V3 with 10k and it sets the slot OV latch), 2 PGOOD (open drain), 3 ID,
  4 RUN (open = on, host pulls low = off), 5 / 6 GND.
- B side parts <= 2.7 mm (7.0 mm gap, host parts <= 2.0 mm); F side
  <= 12 mm; nothing over 1.5 mm within 6.5 mm diameter of a screw.
- Electrical: plane-requirements R1-R22 as in the B doc table (19.0 V
  +/-2 %, current limit 18-20 A, OV cut in hardware independent of the
  converter and any MCU, UVLO ~38 V, OVLO 66-68 V with the plane slot
  tripping first at 64.6 V, 100 V parts on the bus, no wet electrolytics,
  no fuses, no NTC, default on without an MCU).
- ID resistor: B is 22k (B doc decision 6). Decide whether C gets its
  own ID value (pm-interface ID table) or reads as B.

## To decide first (user)

1. **U2 / U3 comparator replacement** (the reason for rev C). Must stay
   an OV cut independent of the converter: own reference, own divider
   from VOUT, supply from VIN (VAUX), open-drain outputs. Candidates,
   stock to be checked with tools/jlc_stock.py:
   - TPS3701DDCR (C132788, ~25k in stock on 2026-10-30, already on the
     module as U4 for OVLO): window comparator, 400 mV references,
     1.8-36 V supply, open drain. One chip could do OV_KILL (OUTB) and
     PGOOD (OUTA); B doc decision 7 rejected that (one die, one supply).
     Two TPS3701, one per function, keeps them independent and uses one
     part number for U2 / U3 / U4. Footprint and pinout differ from the
     MCP65R46: a layout change, dividers recomputed for 400 mV.
   - Other open-drain comparators with an internal reference
     (e.g. TLV3011 family, 1.242 V): check stock, reference accuracy
     and supply range against the OV_KILL worst-case sum below.
   - Whatever is chosen: OV_KILL worst case must stay above 19.31 V
     (VOUT max) plus the load-release overshoot. B has 19.83 V worst
     case (2.4 V +/-2 % ref, VOS, hysteresis, drift, 1 % divider),
     ~0.3 V margin with every tolerance stacked; a 400 mV reference
     with tighter accuracy may improve that.
2. **Defined outputs at low VIN.** With the slot off, module VIN floats
   at ~1.2 V on the bench (cause unknown, handoff 2026-11-25 open item),
   below the comparators' 1.8 V minimum; OV_KILL is then undefined and
   set the slot latch at every switch-off until the plane firmware held
   LCLR while off (ADR 0002 decision 7d). Rev C can fix it on the
   module: a part whose open-drain output is defined (held low or high
   impedance, check the datasheet) down to ~0 V supply, and / or a bleed
   on VIN that holds it under ~0.5 V when off (~40-80k, 30-60 mW on).
   Note which way OV_KILL must fail: low at low VIN sets the latch, which
   7d masks today; high impedance would be cleaner.
3. **Idle loss / diode emulation.** B runs forced continuous (R12 10k on
   DEMB): ~2 W per module with no load, coils ~45 C in air, ~100 W for
   6 blocks. Parked for B (user, 2026-11-26: it works, harmless in the
   fluid). Rev C may keep it or switch to diode emulation (R12 0R) if
   the load-release overshoot is proven against OV_KILL; the bench
   procedure is in docs/handoff.md (2026-11-25, "Parked: bench rework").
4. **Anything else in the B doc's section 7 (open risks)** to fold in
   while the board is open, e.g. a footprint for a cap across the
   OV_KILL divider (R19) in case the 13.2 A load-release overshoot comes
   close to the trip.

Decided, not to reopen: no temperature sensor on the module (user,
2026-11-26: the fluid keeps it cool); module stays a 58.4 x 22.9 plug-in
on the existing units.

## Sourcing rules for rev C

- Every line in JLC stock for at least 100 modules plus attrition, with
  margin (the B module failed on a part with 115 in stock). Check with
  `tools/jlc_stock.py search <part>` while choosing, and
  `tools/jlc_stock.py check pm-c=<bom.csv>=100` on the fab BOM.
- Thin lines on B to re-check: L1 APS1510M100F (191 on 2026-10-30, 50
  now used by batch 2; same-land alternatives FEXL1510A-100M and
  XRFWHP1510A-100M C51913019), and any extended part with < 1000 stock.
- Prefer one part number for several places (TPS3701 for U2 / U3 / U4).
- Datasheets from LCSC: see docs/fd-batch2-order.md, "If a part runs out
  again", step 3.

## Flow and checks

- Schematic from the generator (copy power/pm-19v-250w-b/tools to the
  rev C directory), never hand-edited; layout with pcbkit (pcbkit skill:
  ~/Electronics/pcbkit, KRT router). ERC 0; DRC with
  `--schematic-parity --severity-all --refill-zones`, 0 unconnected,
  0 parity.
- Fab: `pcbkit jlcfab`, then check the CPL in JLC's placement preview,
  **especially the B side**: pcbkit's bottom-side rotation handling
  changed after batch 1 (a fresh B module CPL differs from the batch 1
  one that assembled working modules), so B-side rotations of a fresh
  CPL are unverified.
- Bench before ordering 48: a few rev C modules first (OV_KILL trip with
  a lab supply on VOUT, PGOOD, load-release overshoot with
  tools/sds_capture.py, idle loss, switch-off with the slot off: no
  latch even without 7d).

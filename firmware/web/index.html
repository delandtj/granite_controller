Granite controller

- - -

First setup

This controller has no admin password yet. Set one now; until then the API refuses every other request.

At least 8 characters. There is no default password and no way to read it back.

Recovery token

Write this down together with the MAC address, on paper, before the board is sealed. It is shown once. With it, a factory reset over the network is possible without the admin password.
